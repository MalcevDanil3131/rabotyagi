# Проверка процесса заявок

Консольная интеграционная проверка без дополнительного тестового фреймворка. Использует настоящий PostgreSQL и запускает собранный API на `127.0.0.1:5188`.

`HistoryChecks.cs` дополнительно проверяет весь журнал успешных действий, UTC,
автора, переходы статусов, единственное событие конкурентного назначения,
доступ ролей и отказ посторонним, пустую историю старой заявки, сохранение снимка
имени после блокировки/переименования/удаления. Временный PostgreSQL trigger
намеренно отклоняет вставку события: проверяется откат создания, статуса,
назначения, отчёта с фотографиями и проверки диспетчером. SQL fault injection
разрешён только для базы с префиксом `rabotyagi_checks_`. API перезапускается
на той же временной БД, после чего история сравнивается с исходной.

```sh
dotnet run --project tests/WorkflowChecks
```

Для соединения используются параметры `DefaultConnection` из `rabotyagi/appsettings.json`, host заменяется на localhost. PostgreSQL должен работать, указанный пользователь должен иметь право создать временную базу. Рабочая база приложения не меняется: создаётся `rabotyagi_checks_<случайный ID>`, на неё накатываются миграции, после проверки она удаляется вместе с временными фото. Уже работающий API на других портах не останавливается.

Проверяются вход/выход, роли, отзыв cookie, JSON адреса, очередь и доступ, модерация, слот, конкурентное взятие одним из двух специалистов, начало работы, запрет преждевременного закрытия, multipart-отчёт и фото, неверный формат фото, возврат с комментарием, повторный отчёт, обсуждение, приёмка, закрытие, блокировка и ошибки пароля.

Для ручной проверки интерфейса можно запустить `dotnet run --project tests/WorkflowChecks -- --serve`. После проверок API остаётся запущенным до Enter, затем временная база удаляется. Vite нужно направить на него через `API_PROXY_TARGET=http://127.0.0.1:5188`. Учётные данные существуют только в этой базе: `superadmin@mail.ru` / `Wertukan!234`, `client@checks.local`, `worker1@checks.local`, `worker2@checks.local`, `dispatcher@checks.local` / `Check123!`.
